# GIF project: Your dashboard has three numbers too many

> Fictional demo persona Maya Rivera. Not a real person. Every file here is invented.

The full HyperFrames project is made with `njli new-gif dashboard-three-numbers-too-many` (needs
Node 22 or newer and ffmpeg). A pre-rendered 2 second sample ships at
`drafts/dashboard-three-numbers-too-many/out/sample.gif` so the demo works with Python alone.
