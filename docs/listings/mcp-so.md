## Name

Profile-Wrap  (display name: Profile-Wrap)

## One line

Draft, gate and review LinkedIn posts from your AI assistant; official API only. Independent, not affiliated with LinkedIn.

## Long description

Profile-Wrap helps you plan, write, check and ship LinkedIn posts from your own computer. It writes in your voice in English, Arabic or both as a pair, checks every number against facts you verified yourself (no fact, no number), runs deterministic gates for slop words, private terms, links and Arabic hygiene, and shows every draft on a local review board where you press Allow.

Posting goes through the official LinkedIn API with your own developer app, never through a password login, scraping or a browser robot. It does not read direct messages or send connection invitations. API keys stay in the OS keychain and go only to the AI provider you picked. There is no telemetry.

Profile-Wrap is independent open source software (MIT) and is not affiliated with LinkedIn.
